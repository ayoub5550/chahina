# 🚚 شاحنتي — Chahina

**سوق واحد لنقل البضائع: صاحب السلعة يختار الشاحنة الأرخص والأنسب بنفسه.**

بدل أن يتنقّل التاجر بين الشاحنات ويقبل أول سعر غالٍ يُعرض عليه، يفتح التطبيق فيرى على الخريطة كل الشاحنات القريبة منه، **بصورة كل شاحنة وسعرها لكل عدد كيلومترات وتقييمات زبائنها السابقين**، ثم يقارن ويختار الأرخص أو الأفضل تقييماً ويدردش مع صاحبها مباشرة.

وفي المقابل، صاحب الشاحنة يعرف أن السعر المنخفض = زبائن أكثر، فتُصبح المنافسة في صالح الجميع.

## الفكرة في ثلاث خطوات
1. **التاجر** يحدّد موقعه ووجهته ونوع البضاعة.
2. **التطبيق** يرتّب له الشاحنات القريبة **من الأرخص إلى الأغلى** مع التكلفة التقديرية لرحلته، صورة الشاحنة، الحمولة، والتقييم.
3. **يختار ويدردش ويتفق** — ثم يتابع الشحنة حتى التسليم ويقيّم صاحب الشاحنة.

## المميزات
**للتاجر (صاحب السلعة)**
- خريطة مباشرة بالشاحنات القريبة + فلترة حسب النوع والحمولة والمسافة.
- ترتيب تلقائي بالأرخص، وحساب فوري لتكلفة رحلته حسب تسعيرة كل ناقل.
- صور الشاحنات، الملفات الشخصية، التقييمات والنجوم.
- محادثة مباشرة مع أي ناقل، والمفضّلة لحفظ من يثق بهم.
- طلب شحنة + استقبال عروض أسعار متعددة واختيار الأنسب.
- تتبّع الشحنة، صورة إثبات التسليم، وتقييم متبادل.

**لصاحب الشاحنة**
- ملف شخصي بصورة الشاحنة والنوع والحمولة.
- تسعيرة مرنة يضبطها بنفسه (مثال: 10 كم بـ 2000 دج).
- لوحة تحكم: أرباح الشهر، رسم بياني لآخر 6 أشهر، نسبة قبول العروض، **وترتيبه بين الناقلين في السعر** مع نصيحة لخفضه إذا كان فوق متوسط السوق.
- إشعارات بالطلبات القريبة، ومؤشر «متصل الآن».

**عام**
- ثلاث لغات: العربية (RTL) · الفرنسية · الإنجليزية.
- وضع نهاري/ليلي، تصميم حديث، يعمل كتطبيق PWA على الهاتف.
- الدفع الإلكتروني عبر **Chargily Pay** (بطاقة الذهبية / CIB) أو نقداً.
- تسجيل برقم الهاتف (JWT) بدون أي خدمة مدفوعة، وقاعدة بيانات SQLite على خادمك أنت.
- خرائط OpenStreetMap + Leaflet (بدون مفاتيح مدفوعة).

## المكوّنات
- `web/` — الخادم والواجهة (Node + Express + SQLite + Leaflet).
- `deploy/` — سكربت تنصيب واحد على أي خادم (Node + systemd + Nginx).
- بقية المجلدات — قاعدة تطبيق أندرويد/iOS أصلي (Expo / React Native).

## التشغيل محلياً
```bash
cd web && npm install && npm start   # http://localhost:4000
```

## النشر على خادم
```bash
sudo bash deploy/install.sh
```
التفاصيل والمتغيّرات في `deploy/README.md`.

## الخطوات القادمة
1. توثيق أصحاب الشاحنات (البطاقة الرمادية والرخصة) وشارة «موثّق ✔️» ولوحة إدارة.
2. إشعارات Push على الهاتف.
3. تطبيق أندرويد للنشر على المتاجر.
4. تسعير تلقائي مقترح حسب المسافة والحمولة.

## المساعد الذكي (AI)
يعمل المساعد بنموذج لغوي حقيقي عبر واجهة متوافقة مع OpenAI. المتغيرات في `web/.env`:

```
NVIDIA_API_KEY=...            # مفتاح الوصول (لا يُرفع إلى المستودع)
LLM_MODEL=meta/llama-3.3-70b-instruct
```
إن لم يوجد المفتاح يعمل المساعد تلقائياً بمحرّك القواعد المدمج (بدون توقف).


## الإصدار 5.0

- **دردشة غنية**: صور، مشاركة الموقع، ردود سريعة، علامة قراءة (✓✓).
- **تنبيهات داخل التطبيق** عند وصول عرض أو رسالة أو تغيّر حالة الرحلة.
- **معرض صور الشاحنة** (حتى 6 صور) لصاحب الشاحنة.
- **واجهة عمل للناقل**: إحصائيات مباشرة، حمولات قريبة، إرسال عرض بلمسة واحدة بسعر محسوب من تسعيرته، تعديل التسعيرة، تحديث موقع تلقائي.
- **خط زمني للرحلة** (منشور ← اتفاق ← تحميل ← تسليم) وطلب تقييم تلقائي بعد التسليم.
- **فرز النتائج**: الأرخص / الأقرب / الأعلى تقييماً.
- **لوحة إحصائيات** بالمداخيل والكيلومترات ورسم بياني لآخر 6 أشهر.
- **إدخال صوتي** للمساعد الذكي (ar-DZ / fr / en) وشرح تفاعلي عند أول استعمال، وتنبيه انقطاع الأنترنت.
- صفحة سياسة خصوصية `/privacy.html` وملف متجر Google Play في `store/`.
